# Embodied Regulatory Intelligence in Chaotic Physical Systems

This folder contains supporting materials for the paper:

**Embodied Regulatory Intelligence in Chaotic Physical Systems:  
A Neurosymbolic Cognitive Architecture Coupled to Navier–Stokes Dynamics**

## Purpose of This Folder

The contents of this folder are provided to support transparency, traceability, and independent evaluation of the claims made in the paper. The materials here document the experimental setup, representative results, and illustrative implementation fragments used in the reported experiments.

The experiments described in the paper require execution within the full SpiralBrain v3.0 research system, which is not publicly distributed. Accordingly, the contents of this folder are **not independently executable**.

## What Is Included

- Representative experiment outputs (JSON and derived figures)
- Formal experiment specifications
- Metric definitions
- Sample implementation excerpts (non-executable)
- Figure provenance mapping

## What Is Not Included

- The full SpiralBrain runtime
- Training, tuning, or internal decision logic
- Orchestration or execution scripts required to reproduce runs

This folder is intended as an **evidentiary archive**, not a runnable software package.
