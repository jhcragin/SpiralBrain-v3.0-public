# Regulatory Intelligence Paradigm - Thesis Supporting Materials

This folder contains supporting materials for the thesis "The Regulatory Intelligence Paradigm: Geometric Homeostasis and Elastic Cognition in Synthetic Neurosymbolic Organisms".

## Structure

- `REGULATORY_INTELLIGENCE_PARADIGM.md`: Main thesis document
- `code/`: Benchmark and analysis scripts (wrappers and utilities)
- `data/`: Experimental results and datasets in JSON format
- `figures/`: Visualization and diagram generation scripts

## Usage

The code scripts are designed to run the H-Series experiments and analyze results. They require the full SpiralBrain codebase to execute.

Data files contain logged results from benchmark runs, including cognitive metrics, performance scores, and validation data.

Figure scripts generate visualizations of the system architecture and cognitive attractors.

## Public Repository Note

This thesis package is prepared for public dissemination. It includes only wrapper scripts, results, and analysis tools - no proprietary SpiralBrain core implementation code.
