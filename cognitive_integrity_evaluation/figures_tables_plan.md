# Planned Figures and Tables for Cognitive Integrity Evaluation Paper

This document outlines 5 planned figures and tables to anchor the paper's claims to empirical evidence from the repository. These will be defined before drafting prose to ensure empirical grounding and prevent narrative drift.

## Figure 1: Evaluation as Pressure Schematic
- **Type**: Conceptual diagram
- **Content**: Tripartite model showing evaluation environments as adversarial stressors
  - Observation → Introspective load (reflexive pressure)
  - Benchmarking → Performance constraint distortion (task pressure)
  - Environmental coupling → Boundary integrity stress (interface pressure)
- **Purpose**: Visualizes the core framing that evaluation exerts pressure, inducing regulatory responses
- **Evidence Source**: Observer effect experiment, MMLU reinterpretation, Navier-Stokes coupling docs

## Table 1: Performance Metrics vs Integrity Metrics
- **Type**: Comparative table
- **Content**: Side-by-side columns contrasting traditional vs regulatory evaluation
  - Left: Task accuracy, reward maximization, generalization scores
  - Right: Homeostatic stability, drift bounds, behavioral signature consistency
- **Purpose**: Demonstrates the distinction between behavior and cognition
- **Evidence Source**: H-series experiments, behavioral signatures, regulatory breakthrough docs

## Figure 2: Bounded Degradation Trajectory
- **Type**: Time-series or state-space plot
- **Content**: Depiction of system response under stress showing controlled degradation rather than collapse
  - X-axis: Time/stress level
  - Y-axis: Integrity metrics (coherence, homeostasis)
  - Shows plateau at bounded levels, not runaway divergence
- **Purpose**: Illustrates regulatory preservation of integrity despite performance sacrifice
- **Evidence Source**: MMLU runs, cross-domain coupling results, homeostasis stability data

## Table 2: Stressor-Response Mapping
- **Type**: Summary table
- **Content**: Matrix mapping evaluation pressures to regulatory responses and observed outcomes
  - Rows: Observer effect, MMLU benchmarking, Navier-Stokes coupling
  - Columns: Stressor type, Regulatory response, Observed outcome, Integrity preserved?
- **Purpose**: Provides empirical summary of how different pressures elicit consistent regulatory behavior
- **Evidence Source**: Observer effect results, MMLU reinterpretation, coupling experiment logs

## Figure 3: Behavioral Signature Consistency
- **Type**: Multi-experiment comparison plot
- **Content**: Overlay of response patterns across experiments showing repeatable signatures
  - Shows non-random degradation trajectories
  - Distinguishes regulation from stochastic noise
- **Purpose**: Demonstrates that integrity responses are structured and observable
- **Evidence Source**: Behavioral signatures doc, H-series repeatability, cross-experiment comparisons

## Implementation Notes
- All figures/tables will reference actual data from the SpiralBrain repo
- SpiralBrain appears only as instrument, not subject
- Figures emphasize methodological contribution over system specifics
- Tables focus on generalizable patterns of regulatory response
